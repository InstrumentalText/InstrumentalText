# Comparison of Instrumental Interaction and Interaction Substrates

## Overview

Instrumental Interaction and Interaction Substrates represent two closely related stages in the evolution of interaction design. While both aim to improve the expressiveness and usability of interactive systems, they operate at different conceptual levels.

---

## 1. Core Focus

**Instrumental Interaction**
- Focuses on how users interact with objects through tools (instruments)
- Introduces a mediation layer: User → Instrument → Object
- Emphasizes action execution and feedback

**Interaction Substrates**
- Focuses on how objects are structured and related
- Treats interaction as manipulation of relationships and constraints
- Emphasizes persistent organization rather than single actions

---

## 2. Key Concepts Mapping

| Instrumental Interaction | Interaction Substrates |
|------------------------|----------------------|
| Instruments (tools) | Substrates (interaction spaces) |
| Commands | Constraints |
| Reification (commands → tools) | Reification (effects → relationships) |
| Meta-instruments | Templates / reusable structures |
| Object manipulation | Structure & dependency management |

---

## 3. Conceptual Shift

The transition from Instrumental Interaction to Interaction Substrates reflects a key abstraction shift:

- From **action-based interaction** → **relationship-based interaction**
- From **momentary commands** → **persistent constraints**
- From **tools operating on objects** → **structures organizing objects**

This shift moves interaction design closer to systems that behave more like programmable environments rather than command-driven interfaces.

---

## 4. Evolution Relationship

Interaction Substrates can be seen as an extension of Instrumental Interaction:

1. Instrumental Interaction introduces mediation through tools
2. Interaction Substrates generalizes this by:
   - Embedding behavior into structure
   - Allowing relationships to persist over time
   - Enabling automatic propagation of changes

---

## 5. New Capabilities Enabled

By moving to Interaction Substrates, systems gain:

- **Composability**
  - Multiple relationships can coexist and combine

- **Persistence**
  - Behavior continues without repeated user input

- **Polymorphism**
  - The same relationship can apply across different objects

- **Reusability**
  - Structures can be saved and reused as templates

- **Propagation**
  - Changes automatically update dependent elements

---

## 6. Implications for Interaction Design

This evolution suggests a new paradigm:

> Users should not only perform actions, but define relationships that govern system behavior.

This enables:
- More expressive interaction
- Reduced repetitive actions
- Higher-level control over systems

---

## 7. Toward Instrumental Text

These ideas naturally lead to a language-driven interaction model:

- Users describe **conditions and relationships**
- Systems interpret them as **persistent rules**
- Behavior emerges from **structured interaction logic**

Instrumental Text can be understood as:
> A way to express interaction substrates using natural language

---

## Final Takeaway

Instrumental Interaction explains how interaction is mediated by tools.

Interaction Substrates extends this by showing how interaction can be structured as persistent relationships.

Together, they form a progression from:
**"using tools to act" → "defining structures that behave."**
